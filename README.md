# Photocell

گزارش کار ازمایش  photocell 

نام و نام خانوادگی:مبینا اسحاقی

استاد:اقای دکتر عباسی

عنوان آزمایش: استفاده از سنسور photocell برای کنترل روشن و خاموش کردن لامپ

هدف آزمایش: 

هدف از این آزمایش یادگیری نحوه استفاده از سنسور photocell برای کنترل روشن و خاموش کردن لامپ بر اساس شدت نور محیط است.

وسایل مورد نیاز:

برد آردوینو (Arduino Uno) 💻

سنسور photocell 🌞

لامپ یا LED 💡

مقاومت‌ها (برای photocell و LED)

سیم‌ها 🔌

لپ‌تاپ یا کامپیوتر برای برنامه‌نویسی آردوینو 💻

نرم‌افزار آردوینو IDE 🖥️


شرح آزمایش:

اتصال قطعات:

سنسور photocell به یکی از ورودی‌های آنالوگ آردوینو (مثلاً A0) وصل می‌شود تا مقدار نور محیط خوانده شود. 🌞

پایه مثبت LED به یکی از پایه‌های دیجیتال آردوینو (مثلاً 13) وصل می‌شود. 💡

پایه منفی LED به پایه GND آردوینو وصل می‌شود. 🔴


عملکرد:

اگر شدت نور بیشتر از 800 باشد، لامپ خاموش می‌شود.

اگر شدت نور کمتر از 800 باشد، لامپ روشن می‌شود.

نتیجه‌گیری: این آزمایش به شما کمک می‌کند تا با استفاده از سنسور photocell شدت نور محیط را سنجیده و بر اساس آن لامپ را روشن یا خاموش کنید. این سیستم می‌تواند در اتوماسیون خانگی یا پروژه‌های مشابه کاربرد داشته باشد.
